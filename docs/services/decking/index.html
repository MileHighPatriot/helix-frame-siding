What is in the scope

  • Ledger flashing and structural attachment to the rim
  • Posts, beams, joists, and stair stringers
  • Composite, cedar, and hardwood walking surfaces
  • Guards and handrails that pass the local code check

Typical sequence

  1. 01Confirm height, drainage, and the door threshold
  2. 02Set the frame and have it inspected before the decking hides it
  3. 03Install the surface, picture-frame borders, and stairs
  4. 04Finish with guards tied back to the structure
