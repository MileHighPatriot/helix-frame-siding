What is in the scope

  • Floor systems, shear walls, and roof framing
  • Engineered beams, flush beams, and point loads
  • Stair openings, window packages, and temporary weather protection
  • Layout that matches the drawings, not a guess at the chalk line

Typical sequence

  1. 01Verify the foundation or existing plate before the first stud stands
  2. 02Stand walls, set beams, and roll the roof
  3. 03Sheathe and brace so the inspector sees a complete load path
  4. 04Hand the dried-in shell to the envelope crew
